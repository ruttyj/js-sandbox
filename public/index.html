Global Variables

Global variables can be used in any scope. A scope's own const with the same name overrides the global one.

globals.js

Tips

  • Written the same way as scopes: the code runs top to bottom, and each top-level const / let is one global. Declare a global before using it.
  • // comment lines directly above a declaration become its description. Use // @tags: A, B to tag it for the Dashboard.
  • getOsrsItem('Oathplate helm').lowPrice works here too.
  • ui.table(...), ui.items(...) and the rest work here too (see the Scopes tab's tips); they show in a UI section at the top of this tab.
  • End with return { A, B }; to make only A and B visible to scopes and the Dashboard; the rest stay private. Without a return, every global is public.
