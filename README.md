# GE Tracker · Price Computation Suite

A browser-based tool for tracking Old School RuneScape Grand Exchange prices and computing values with formulas.

## ▶ [Open the app](https://ruttyj.github.io/js-sandbox/)

The app runs entirely in your browser — no install or build step needed. Just open the link above.

## Running locally

Clone the repo and open `index.html` in a browser:

```
git clone https://github.com/ruttyj/js-sandbox.git
```
